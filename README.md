# conference-archive

A personal archive of conference talks, speaking engagements, and other career references that exist on pages at risk of disappearing from the live web — saved here as raw HTML, plain-text extracts, and (where available) screenshots, so the record survives even if the original site and the Wayback Machine both go away.

Each event gets its own subfolder with a short README explaining what it is, why it's archived, and the original + permanent (Wayback Machine) links.
