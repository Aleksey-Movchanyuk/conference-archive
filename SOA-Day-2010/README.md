# SOA-Day 2010

**Event:** "SOA-Day. Теория и практика сервисно-ориентированной архитектуры" ("SOA-Day. Theory and practice of service-oriented architecture") — 23 June 2010, Kyiv. Organised by the Community of IT Directors of Ukraine and the Banking IT Club.

**Talk:** "Интеграция данных на основе SOA при построении Real-Time 'Витрин данных' ('Data Mart')" ("SOA-based data integration for building real-time data marts") — Aleksey Movchaniuk, listed as Solutions Architect, Borlas Ukraine.

## Why this is archived here
The original event pages on the organizer's site (itdirector.org.ua) are gone from the live web — the site has since been restructured and the 2010 program page no longer resolves. This folder preserves what was recoverable via the Wayback Machine before it disappears from there too.

## Contents
- `organizer_program_page_WAYBACK.html` — full saved HTML of the organizer's own program page, as captured by the Wayback Machine on 2016-04-15 (original URL: `http://itdirector.org.ua/itforum/meropr/SOA-Day/Programa.php`)
- `press_release_WAYBACK.html` — full saved HTML of an independent press write-up on atrex.ru, captured by the Wayback Machine on 2015-04-19 (original URL: `http://atrex.ru/press/p52894.html`), published the day after the event
- `organizer_program_page_extracted.txt` / `atrex_press_release_extracted.txt` — plain-text extracts of the above, for quick reference without rendering HTML
- `screenshot_organizer_program_page.png` / `screenshot_press_release.png` — screenshots of both Wayback Machine pages, with the browser address bar and the Wayback toolbar (original URL + capture date) visible
- `screenshot_google_search_confirmation.png` — Google search result for "алексей мовчанюк soa", showing the AI Overview summary and the original search snippet "Докладывает Алексей Мовчанюк, Борлас Украина" (with photo thumbnail) from `old.itdirector.org.ua`, confirming the same event/person independently of the two sources above
