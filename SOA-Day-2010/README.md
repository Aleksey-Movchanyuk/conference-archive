# SOA-Day 2010

**Event:** "SOA-Day. Теория и практика сервисно-ориентированной архитектуры" ("SOA-Day. Theory and practice of service-oriented architecture") — 23 June 2010, Kyiv. Organised by the Community of IT Directors of Ukraine and the Banking IT Club.

**Talk:** "Интеграция данных на основе SOA при построении Real-Time 'Витрин данных' ('Data Mart')" ("SOA-based data integration for building real-time data marts") — Aleksey Movchaniuk, listed as Solutions Architect, Borlas Ukraine.

## Why this is archived here
The original event pages on the organizer's site (itdirector.org.ua) are gone from the live web — the site has since been restructured and the 2010 program page no longer resolves. This folder preserves what was recoverable via the Wayback Machine before it disappears from there too.
