# DEV Labs 2013 (Luxoft "Soft Labs" conference series)

**Event:** "DEV Labs 2013" — an online conference on Oracle software products, part of Luxoft's "Soft Labs" conference series. Held Saturday, 5 October 2013 (talk times in Moscow time).

**Talk:** "«Big Data» & Oracle Technologies" — Aleksey Movchaniuk, listed as Lead Consultant, Practic Consulting. Opening talk of the day, 12:00–13:30 Moscow time.

## Why this is archived here
The organizer's own site (soft-labs.net) no longer resolves live. This folder preserves what was recoverable via the Wayback Machine before it disappears from there too.

## Contents
- `speakers_list_WAYBACK.html` — full saved HTML of the organizer's official speaker list, as captured by the Wayback Machine on 2014-08-10 (original URL: `http://www.soft-labs.net/dev-labs2013-oracle/agenda/speakers_list/856`)
- `agenda_WAYBACK.html` — full saved HTML of the organizer's official conference agenda, captured by the Wayback Machine on 2019-12-06 (original URL: `http://www.soft-labs.net/dev-labs2013-oracle/agenda/`)
- `speakers_list_extracted.txt` / `agenda_extracted.txt` — plain-text extracts of the above, for quick reference without rendering HTML
